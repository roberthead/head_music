# Learnings

Lessons from finished stories that should change how the next one is planned, built, or reviewed. Read before planning a story.

## Planning

- **Run every claim about current behavior before it enters a story or plan.** Story notes have named a method that returns something else (`guide.name`), miscounted classes, cited tags that exist only locally, and described errors the code never raised. A ten-second probe found each; reading found none. Sources: user-stories/done/rename-annotation-to-guideline.md, user-stories/done/guard-the-vocabulary-sweep-itself.md, user-stories/done/abc-voices-and-meter-changes.md, user-stories/done/release-notes-for-19-0-0.md, user-stories/done/composite-guides.md, user-stories/done/configurable-guide-registry.md, user-stories/done/british-note-names.md, user-stories/done/musicxml-instrument-fallback.md, user-stories/done/spans-across-notes.md, user-stories/done/sound-model.md, user-stories/done/rhythmic-duration.md
- **Measure a threshold or design choice against the corpus before choosing it.** Throwaway scripts over the pinned corpus or real files overturned the plausible answer each time: Aarden over Krumhansl–Kessler, the three-quarter contour share, the MIDI grid rule, which note names collide. Sources: user-stories/done/accidental-string-normalization.md, user-stories/done/grade-contour-misses-by-degree.md, user-stories/done/key-and-spelling-inference.md, user-stories/done/improve-melodic-contour-guidelines.md, user-stories/done/embellish-fifth-species-suspensions.md, user-stories/done/midi-import.md, user-stories/done/note-values-in-each-language.md, user-stories/done/extract-the-harmonic-cores.md, user-stories/done/require-the-species-rhythm.md
- **Settle the model and the open decisions before planning, and land the model before its formats.** Once the content model was fixed, each format story was plumbing; decisions left open became rework. Sources: user-stories/done/chord-placement-model.md, user-stories/done/abc-chord-input.md, user-stories/done/abc-notation-beaming.md, user-stories/done/articulations-ornaments-dynamics.md, user-stories/done/lyric-extenders.md, user-stories/done/lyrics.md, user-stories/done/hairpins.md, user-stories/done/sound-model.md, user-stories/done/scoring-architecture.md, user-stories/done/melody-contour-guides.md
- **Check what the sibling readers and writers do with the same musical shape.** LilyPond already answered how a bar-1 field reads; MusicXML, MEI, and kern already kept the part name LilyPond was about to record as a loss. Sources: user-stories/done/abc-voices-and-meter-changes.md, user-stories/done/lilypond-transposition-round-trip.md
- **Re-derive a deferral's reason; don't inherit it.** `#11` extensions, LilyPond chords, and `rudiments.meter` were each deferred for a reason that failed when checked. Sources: user-stories/done/accidental-string-normalization.md, user-stories/done/british-note-names.md, user-stories/done/lilypond-interpreter.md
- **Read the cited source itself, and look on disk first.** Paraphrase misdescribed a Salzer–Schachter example twice; Adler and Mann were local scans. Transcribe an example before writing criteria around it, and ask which tradition a source describes. Sources: user-stories/done/cambiata-and-double-neighbor-fifth-note.md, user-stories/done/banjo-notation-transpositions.md, user-stories/done/require-the-species-rhythm.md, user-stories/done/fifth-species-guide-improvements.md, user-stories/done/grade-every-fux-fifth-species-figure.md
- **Write criteria that state a shape, not a number or a universal.** A frozen fitness fought adjustable scoring; "for any composition" and "compiles with no warnings" were unsatisfiable; "move the strings" passed while 103 strings went unwritten. Reword a criterion when the build settles it differently, and split the story when scope widens twice. Sources: user-stories/done/re-tier-the-guides.md, user-stories/done/composition-serialization.md, user-stories/done/hairpins.md, user-stories/done/guideline-strings-into-i18n.md, user-stories/done/scoring-architecture.md, user-stories/done/species-guide-harmonic-weights.md, user-stories/done/humdrum-kern-import-and-export.md, user-stories/done/musicxml-instrument-fallback.md
- **Explain the mechanism and its terms, with an example, before asking Rob to decide.** Questions that led with a term came back as questions. Sources: user-stories/done/bar-markings.md, user-stories/done/markings-review-follow-ups.md, user-stories/done/spans-across-notes.md, user-stories/done/embellish-fifth-species-suspensions.md

## Grading and guidelines

- **After any guideline change, regenerate the corpus snapshot and read the moved rows as melodies.** Guideline specs passed while the snapshot lowered voices that only had a figure's pitch shape, and exposed cantus firmus voices graded against a florid partner. Predict movement only after reading the gates. Sources: user-stories/done/cambiata-and-double-neighbor-fifth-note.md, user-stories/done/embellish-fifth-species-suspensions.md, user-stories/done/grade-contour-misses-by-degree.md, user-stories/done/free-species-guide.md, user-stories/done/grade-every-fux-fifth-species-figure.md
- **One cause per capture.** Guessing a row's cause mislabelled 205 rows, and a fixture added between captures drops out of the join. Record the measuring commit beside each number; count a row as moved when any column changes. Sources: user-stories/done/extract-the-harmonic-cores.md, user-stories/done/species-guide-harmonic-weights.md, user-stories/done/re-tier-the-guides.md, user-stories/done/grade-every-fux-fifth-species-figure.md, user-stories/done/fifth-species-guide-improvements.md
- **A green suite does not show that grades or output held.** Nothing grades a voice against a non-matching guide, and a dropped guideline still yields a plausible number. For "no behavior change", capture before the first edit and diff. Sources: user-stories/done/re-tier-the-guides.md, user-stories/done/rename-annotation-to-guideline.md, user-stories/done/first-class-guide-items.md, user-stories/done/composite-guides.md, user-stories/done/configurable-guide-registry.md, user-stories/done/configurable-large-leap-recovery.md, user-stories/done/notation-style.md, user-stories/done/mei-export.md
- **Delete each clause, or revert the change, and confirm an example fails.** Specs repeatedly passed for the wrong reason: a negative example that failed on consonance, not direction; guards aimed at `en_GB` when Russian needed them. A negative example should break exactly one clause. Sources: user-stories/done/escape-tone-recognition.md, user-stories/done/improve-melodic-contour-guidelines.md, user-stories/done/fifth-species-guide-improvements.md, user-stories/done/melody-contour-guides.md, user-stories/done/composite-guides.md, user-stories/done/configurable-guide-registry.md, user-stories/done/guideline-strings-into-i18n.md, user-stories/done/note-values-in-each-language.md, user-stories/done/markings-review-follow-ups.md, user-stories/done/lyric-extenders.md
- **Read rhythm from positions and the meter, never from beat numbers.** "Beat 3" rules were silently wrong in 3/2 and cut time, and "group by beat" beamed nothing in 3/8. Sources: user-stories/done/fifth-species-guide-improvements.md, user-stories/done/embellish-fifth-species-suspensions.md, user-stories/done/abc-notation-beaming.md
- **Decide how a line-walking rule treats rests and ties, and pin each.** `voice.notes` drops rests, the figure predicates read through them, and a tied note is judged by its attack. Sources: user-stories/done/free-species-guide.md, user-stories/done/escape-tone-recognition.md, user-stories/done/rhythmic-duration.md
- **Guide declarations leak silently through inheritance.** Gates declared on a base class left subclasses with none, and `RULESET` resolved up the ancestor chain to a plausible wrong ruleset; nothing raised. Sources: user-stories/done/re-tier-the-guides.md, user-stories/done/configurable-guide-registry.md
- **Where a fallback exists, "it renders" is not evidence.** Count what uses the fallback: zero of 55 guidelines had an instruction. `I18n.exists?` needs `fallback: false`, and `Named#name` answers English in every locale. Sources: user-stories/done/guideline-strings-into-i18n.md, user-stories/done/musicxml-instrument-fallback.md, user-stories/done/british-note-names.md

## Formats

- **Run every fixture shape through the real tool.** LilyPond exits 0 while warning; abcm2ps, Verovio, MuseScore, and the MEI schema each rejected output the specs accepted. Follow what the renderer draws. Sources: user-stories/done/lilypond-export.md, user-stories/done/bar-markings.md, user-stories/done/abc-voices-and-meter-changes.md, user-stories/done/spans-across-notes.md, user-stories/done/hairpins.md, user-stories/done/mei-export.md, user-stories/done/midi-export.md, user-stories/done/lyric-extenders.md, user-stories/done/musicxml-instrument-fallback.md, user-stories/done/lilypond-transposition-round-trip.md
- **Build round trips from the richest document, compare the first parse, and assert positions.** Sparse documents hid missing fields, later-generation comparisons hid first-parse loss, and level-in-force checks hid moved dynamics. Add a seeded generator covering marks on tied and barline-split notes. Sources: user-stories/done/content-architecture.md, user-stories/done/humdrum-kern-import-and-export.md, user-stories/done/markings-review-follow-ups.md, user-stories/done/spans-across-notes.md, user-stories/done/hairpins.md, user-stories/done/tuplets-and-grace-notes.md, user-stories/done/timeline-expressions.md
- **Give every reader both a real-corpus sweep and an adversarial review.** Corpora show what exporters write, which differs from "valid"; keep a manifest of named exclusions. Only hostile documents found non-`ParseError` escapes, including code that runs before its guard. Sources: user-stories/done/abc-notation-interpreter.md, user-stories/done/lilypond-interpreter.md, user-stories/done/musicxml-import.md, user-stories/done/mei-import.md, user-stories/done/midi-import.md, user-stories/done/mei-export.md
- **New data breaks old shared helpers, not the new model.** List the helpers that compute from a flow's timeline or parts and check each. Lifting a refusal means auditing every consumer it protected. Sources: user-stories/done/articulations-ornaments-dynamics.md, user-stories/done/abc-voices-and-meter-changes.md, user-stories/done/hairpins.md, user-stories/done/require-the-species-rhythm.md, user-stories/done/markings-review-follow-ups.md, user-stories/done/lilypond-export.md
- **Widening a reader must not turn an error into a plausible wrong answer.** Accepting `##` made `Cx` read as a key with no accidentals; accepting `<>` dropped its marks. Check each change against what writers accept, not only what they emit. Sources: user-stories/done/accidental-string-normalization.md, user-stories/done/hairpins.md, user-stories/done/place-dynamics-where-no-note-starts.md
- **Refuse, naming the mark; never pad, filter, or reinterpret.** Factories disagree on garbage: `KeySignature.get("Q major")` returns a hollow truthy object, `Pitch.get("A44")` answers A4. Sources: user-stories/done/bar-markings.md, user-stories/done/identity-and-presentation.md, user-stories/done/abc-chord-input.md, user-stories/done/place-dynamics-where-no-note-starts.md, user-stories/done/composition-serialization.md, user-stories/done/sound-model.md
- **Pin "linear" with a call-counting spec.** Quadratic shared helpers passed every corpus; wall-clock timing is useless on this machine. Sources: user-stories/done/mei-import.md, user-stories/done/midi-import.md, user-stories/done/midi-export.md, user-stories/done/tuplets-and-grace-notes.md, user-stories/done/musicxml-import.md

## Parallel agents

- **Freeze the contract and shared helpers in a base commit, then fan out by format.** Pinned signatures and disjoint files gave conflict-free integration; agents left alone wrote five bar lookups. Hold CHANGELOG lines for the coordinator, and keep its integrated round trip: a reader and writer built apart disagreed twice. Sources: user-stories/done/abc-notation-export.md, user-stories/done/abc-notation-interpreter.md, user-stories/done/bar-markings.md, user-stories/done/hairpins.md, user-stories/done/place-dynamics-where-no-note-starts.md, user-stories/done/mei-export.md, user-stories/done/mei-import.md, user-stories/done/midi-export.md, user-stories/done/musicxml-import.md, user-stories/done/tuplets-and-grace-notes.md
- **Give each worktree agent its base commit and its own scratch folder.** Agents start at `main`; a sandbox hook refuses commands containing "git", which the repository path does, so make worktrees by hand. After a restart, check for a peer session. Sources: user-stories/done/bar-markings.md, user-stories/done/musicxml-import.md, user-stories/done/midi-export.md, user-stories/done/tuplets-and-grace-notes.md, user-stories/done/mei-export.md, user-stories/done/mei-import.md
- **Reproduce each agent finding before recording it.** Reviewers reported missing specs that existed and a planner reported specialists that never ran, yet most findings held; reproduction changed severities and causes. Sources: user-stories/done/articulations-ornaments-dynamics.md, user-stories/done/identity-and-presentation.md, user-stories/done/timeline-expressions.md, user-stories/done/note-values-in-each-language.md, user-stories/done/improve-melodic-contour-guidelines.md, user-stories/done/banjo-notation-transpositions.md
- **Your own edits and prose are the least reviewed part of the diff.** Hand-written changes carried four defects in one story; comments, story numbers, and CHANGELOG text drifted from the code. Write the CHANGELOG from the captured diff, and mark **Breaking.** only against the last release tag. Sources: user-stories/done/first-class-guide-items.md, user-stories/done/rename-annotation-to-guideline.md, user-stories/done/grade-every-fux-fifth-species-figure.md, user-stories/done/british-note-names.md, user-stories/done/place-dynamics-where-no-note-starts.md

## Tooling

- **Edit files with the Edit tool, not shell heredocs or `sed`.** Heredocs mangled backslashes and apostrophes and ran backticked names as commands; BSD `sed` silently ignores `\b`. Sources: user-stories/done/bar-markings.md, user-stories/done/lilypond-export.md, user-stories/done/lilypond-interpreter.md, user-stories/done/lilypond-transposition-round-trip.md, user-stories/done/place-dynamics-where-no-note-starts.md, user-stories/done/midi-export.md, user-stories/done/midi-import.md, user-stories/done/rhythmic-duration.md, user-stories/done/rename-annotation-to-guideline.md
- **Measure CPU time, and suspect the machine before the code.** Load from 5 to 48 distorted every wall-clock number, and a laptop asleep on battery makes agents look stuck (`pmset -g log`). Sources: user-stories/done/faster-test-suite.md, user-stories/done/musicxml-import.md, user-stories/done/tuplets-and-grace-notes.md, user-stories/done/key-and-spelling-inference.md, user-stories/done/midi-import.md
- **Know the spec infrastructure's traps.** `spec/support` modules are included globally, so prefix private helpers. Requiring `spec_helper` outside RSpec poisons `coverage/.last_run.json`. The gemspec globs `git ls-files`, so keep scratch files out of the repository. Deep-freezing breaks lazily memoizing rudiments. Commit before running a mutation harness. Sources: user-stories/done/lilypond-interpreter.md, user-stories/done/rename-annotation-to-guideline.md, user-stories/done/first-class-guide-items.md, user-stories/done/guideline-strings-into-i18n.md, user-stories/done/spans-across-notes.md
